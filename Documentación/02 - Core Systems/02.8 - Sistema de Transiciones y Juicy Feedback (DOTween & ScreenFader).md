# 02.8 - Sistema de Transiciones y Juicy Feedback (DOTween & ScreenFader)

## 🎯 Propósito Arquitectural

Para elevar la calidad sensorial (*Game Feel* y *Juiciness*) del Proof of Concept y emular el ritmo cinematográfico del Survival Horror clásico sin recurrir a complejas máquinas de animación (*Animator Controllers*) para cada elemento inerte, el proyecto integra **DOTween** (Demigiant) como motor de interpolación matemática por código.

Adicionalmente, se introduce el subsistema centralizado [[05 - Scripts C# (Arquitectura Unity)/UI/ScreenFader.cs|ScreenFader]], un singleton persistente de interfaz gráfica responsable de oscurecer y aclarar la pantalla durante cambios de nivel, transiciones narrativas y secuencias de muerte.

---

## 🏗️ Principios de Integración de DOTween

1. **Gestión del Ciclo de Vida y Prevención de Fugas de Memoria**:
   - Todo tween activo sobre un `Transform` o `CanvasGroup` debe cancelarse antes de iniciar uno nuevo o al destruirse el objeto anfitrión:
     ```csharp
     transform.DOKill();
     ```
2. **Independencia de la Escala de Tiempo (`SetUpdate(true)`)**:
   - Los elementos de interfaz de usuario (`InventoryUI`, `ScreenFader`) operan incluso cuando la máquina de estados congela o ralentiza el juego (`Time.timeScale = 0`). Para ello se encadenan con `.SetUpdate(true)` (empleando `unscaledTime`).
3. **Curvas de Aceleración Orgánicas (`Ease`)**:
   - `Ease.InOutQuad` / `Ease.OutQuad`: Utilizadas para la apertura lenta y tensa de puertas de madera/metal.
   - `Ease.OutBack` / `Ease.OutBounce`: Empleadas en aperturas de menús, pop-ins y recogida elástica de suministros.
   - `Ease.InCubic`: Utilizada para fundidos acelerados a negro en transiciones de supervivencia.

## 💻 Implementación de `ScreenFader.cs`

```csharp
using System;
using UnityEngine;
using UnityEngine.UI;
using DG.Tweening;
using Game.Core;

namespace Game.UI {
    /// <summary>
    /// Singleton persistente para fundidos a negro y transiciones cinematográficas
    /// de pantalla completa usando DOTween.
    /// </summary>
    public class ScreenFader : PersistentSingleton<ScreenFader> {
        [Header("Configuración de Fade")]
        [SerializeField] private CanvasGroup _canvasGroup;
        [SerializeField] private Image _fadeImage;

        private Tween _currentFadeTween;

        protected override void Awake() {
            base.Awake();
            EnsureCanvasSetup();
        }

        private void EnsureCanvasSetup() {
            if (_canvasGroup == null) {
                _canvasGroup = GetComponentInChildren<CanvasGroup>();
                if (_canvasGroup == null) {
                    var canvasObj = new GameObject("Fader_CanvasGroup");
                    canvasObj.transform.SetParent(transform, false);
                    _canvasGroup = canvasObj.AddComponent<CanvasGroup>();
                }
            }

            var canvas = GetComponent<Canvas>();
            if (canvas == null) {
                canvas = gameObject.AddComponent<Canvas>();
                canvas.renderMode = RenderMode.ScreenSpaceOverlay;
                canvas.sortingOrder = 999; // Máxima prioridad visual
                gameObject.AddComponent<GraphicRaycaster>();
            }

            if (_fadeImage == null) {
                _fadeImage = _canvasGroup.GetComponentInChildren<Image>();
                if (_fadeImage == null) {
                    var imgObj = new GameObject("BlackOverlay", typeof(RectTransform), typeof(Image));
                    imgObj.transform.SetParent(_canvasGroup.transform, false);
                    _fadeImage = imgObj.GetComponent<Image>();
                    _fadeImage.color = Color.black;

                    var rt = imgObj.GetComponent<RectTransform>();
                    rt.anchorMin = Vector2.zero;
                    rt.anchorMax = Vector2.one;
                    rt.sizeDelta = Vector2.zero;
                }
            }

            _canvasGroup.alpha = 0f;
            _canvasGroup.blocksRaycasts = false;
        }

        /// <summary>
        /// Funde la pantalla a negro.
        /// </summary>
        public void FadeOut(float duration = 1.0f, Action onComplete = null) {
            _currentFadeTween?.Kill();
            _canvasGroup.blocksRaycasts = true;

            _currentFadeTween = _canvasGroup.DOFade(1f, duration)
                .SetEase(Ease.InOutQuad)
                .SetUpdate(true)
                .OnComplete(() => {
                    onComplete?.Invoke();
                });
        }

        /// <summary>
        /// Aclara la pantalla desde negro.
        /// </summary>
        public void FadeIn(float duration = 1.0f, Action onComplete = null) {
            _currentFadeTween?.Kill();

            _currentFadeTween = _canvasGroup.DOFade(0f, duration)
                .SetEase(Ease.InOutQuad)
                .SetUpdate(true)
                .OnComplete(() => {
                    _canvasGroup.blocksRaycasts = false;
                    onComplete?.Invoke();
                });
        }
    }
}
```

## 🎨 Matriz de Feedback Sensorial Implementado

| Subsistema / Script | Tipo de Tween | Propósito Sensorial |
| :--- | :--- | :--- |
| **`DoorInteractable`** | `DOLocalRotate` + `DOShakeRotation` | Giro orgánico según la orientación del jugador; vibración angular si la puerta está atrancada sin llave. |
| **`DoorInteractable`** | `DOPunchScale(0.12f)` | Sacudida de impacto al abrir de golpe (*burst open*) con doble pulsación. |
| **`ItemPickup`** | `DOMoveY` (Yoyo) + `DORotate` | Flotación suave y giro continuo en el escenario 3D sin coste de físicas. |
| **`ItemPickup`** | `DOScale` + `DOMoveY` (Secuencia) | Levantamiento elástico y reducción a 0 antes de destruir el objeto recogido. |
| **`PushableBox`** | `DOPunchScale(0.1f)` | Reacción física elástica al encajar en sockets azules o rojos. |
| **`BoxDestinationPoint`** | `DOPunchScale(0.15f)` | Vibración y resplandor de la base en el suelo al registrar una caja. |
| **`CombatUI`** | `DOShakePosition` + `DOPunchScale` | Retroceso de la cámara de combate al disparar y parpadeo de daño en la diana. |
| **`InventoryUI`** | `DOScale(1f, 0.2s)` (Ease.OutBack) | Apertura elástica del maletín y confirmación táctil al soltar o usar objetos. |
