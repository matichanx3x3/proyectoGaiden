# 02.4 - Sistema de Recursos y ScriptableObjects (ResourceSystem & Scriptables)

El `ResourceSystem` es el repositorio central de datos del juego. En lugar de dispersar llamadas costosas a `Resources.Load<T>()` en momentos aleatorios del gameplay, este sistema precarga todos los `ScriptableObjects` durante la inicialización y los almacena en colecciones optimizadas (`Dictionary<TKey, TValue>`).

Esto aplica directamente lo visto en [[04.2 - Programacion Orientada a Objetos en CSharp|Programación Orientada a Objetos (ScriptableObjects)]] y [[04.4 - Genericos y Colecciones en el Motor de Juego|Genéricos y Colecciones (Diccionarios)]].

## 💻 Implementación de `ResourceSystem.cs` para Gaiden

```csharp
using System.Collections.Generic;
using System.Linq;
using UnityEngine;
using Gaiden.Units;
using Gaiden.Weapons;
using Gaiden.Items;

namespace Gaiden.Core {
    public class ResourceSystem : StaticInstance<ResourceSystem> {
        // Colecciones en memoria
        public List<ScriptableHero> Heroes { get; private set; }
        public List<ScriptableEnemy> Enemies { get; private set; }
        public List<ScriptableWeapon> Weapons { get; private set; }
        public List<ScriptableItem> Items { get; private set; }

        // Diccionarios para búsqueda instantánea O(1)
        private Dictionary<HeroId, ScriptableHero> _heroesDict;
        private Dictionary<EnemyType, ScriptableEnemy> _enemiesDict;
        private Dictionary<WeaponType, ScriptableWeapon> _weaponsDict;
        private Dictionary<ItemId, ScriptableItem> _itemsDict;

        protected override void Awake() {
            base.Awake();
            AssembleResources();
        }

        private void AssembleResources() {
            // Carga de Héroes (Barry, Leon, Lucia)
            Heroes = Resources.LoadAll<ScriptableHero>("Units/Heroes").ToList();
            _heroesDict = Heroes.ToDictionary(h => h.HeroId, h => h);

            // Carga de Enemigos (Zombies, Cerberus, Tyrant)
            Enemies = Resources.LoadAll<ScriptableEnemy>("Units/Enemies").ToList();
            _enemiesDict = Enemies.ToDictionary(e => e.EnemyType, e => e);

            // Carga de Armas (Cuchillo, Handgun, Shotgun, etc.)
            Weapons = Resources.LoadAll<ScriptableWeapon>("Weapons").ToList();
            _weaponsDict = Weapons.ToDictionary(w => w.WeaponType, w => w);

            // Carga de Objetos (Hierbas, Botiquines, Llaves)
            Items = Resources.LoadAll<ScriptableItem>("Items").ToList();
            _itemsDict = Items.ToDictionary(i => i.ItemId, i => i);

            Debug.Log($"[ResourceSystem] Precargados: {Heroes.Count} héroes, {Enemies.Count} enemigos, {Weapons.Count} armas, {Items.Count} items.");
        }

        // Métodos de consulta O(1)
        public ScriptableHero GetHero(HeroId id) => _heroesDict[id];
        public ScriptableEnemy GetEnemy(EnemyType type) => _enemiesDict[type];
        public ScriptableWeapon GetWeapon(WeaponType type) => _weaponsDict[type];
        public ScriptableItem GetItem(ItemId id) => _itemsDict[id];
        
        // Método aleatorio (útil para encuentros casuales en pasillos)
        public ScriptableEnemy GetRandomZombie() {
            var zombies = Enemies.Where(e => e.EnemyType != EnemyType.TyrantBow).ToList();
            return zombies[Random.Range(0, zombies.Count)];
        }
    }
}
```

## 📦 Definición de los ScriptableObjects

### 1. `ScriptableHero` (Datos Base de Barry, Leon, Lucia)
```csharp
[CreateAssetMenu(menuName = "Gaiden/Units/Hero", fileName = "NewHero")]
public class ScriptableHero : ScriptableObject {
    public HeroId HeroId;
    public string CharacterName;
    public int MaxHealth;
    public Sprite PortraitSprite;
    public Sprite OverworldSprite;
    public GameObject Prefab;
}
```

### 2. `ScriptableEnemy` (Zombies y Parámetros del Retículo)
Representa los datos desensamblados del Banco `0D` de la ROM:
```csharp
[CreateAssetMenu(menuName = "Gaiden/Units/Enemy", fileName = "NewEnemy")]
public class ScriptableEnemy : ScriptableObject {
    public EnemyType EnemyType;
    public string EnemyName;
    public int MaxHealth;
    public int AttackPower;
    
    [Header("Parámetros del Retículo de Combate")]
    [Range(4, 30)] public int HitHalfWidth;    // Ancho de la zona de impacto normal
    [Range(1, 8)]  public int CritHalfWidth;   // Ancho de la diana crítica
    [Range(60, 300)] public int AttackIntervalFrames; // Contador antes del golpe enemigo
    
    public Sprite BattleSprite;
    public GameObject OverworldPrefab;
}
```

### 3. `ScriptableWeapon` (Armamento y Multiplicador Crítico)
```csharp
[CreateAssetMenu(menuName = "Gaiden/Items/Weapon", fileName = "NewWeapon")]
public class ScriptableWeapon : ScriptableObject {
    public WeaponType WeaponType;
    public string WeaponName;
    public int BaseDamage;
    public int CritMultiplier; // x2 o x3
    public int MaxAmmoCapacity;
    public AudioClip FireSound;
    public Sprite Icon;
}
```

## 🎯 Por Qué Esta Arquitectura es Superior a Clases Normales

1. **Memoria Compartida (Flyweight Pattern)**:
   - Cien zombies instanciados en una sala comparten **la misma instancia en memoria** del `ScriptableEnemy`. Ningún dato estático se duplica.
2. **Edición en Tiempo Real (Live Tweaking)**:
   - El diseñador puede cambiar el `HitHalfWidth` o el `AttackPower` durante el juego en el Inspector de Unity y el cambio surte efecto en el siguiente ataque sin reiniciar el juego.
