# 03.3 - Sistema de Grupo y Personajes (Party System)

En *Resident Evil Gaiden*, el jugador no controla a un único superviviente estático, sino a un **grupo de hasta 3 personajes**:
1. **Barry Burton**: El veterano de S.T.A.R.S. y protagonista principal (100 HP).
2. **Leon S. Kennedy**: Agente del gobierno infiltrado en el Starlight (100 HP).
3. **Lucia**: Niña misteriosa con poderes biológicos (120 HP).

En la ROM original (`decompgaiden/src/player.c`), la presencia en el grupo se almacenaba en `0xC386`, sus puntos de vida en `0xC3BC` y el personaje activo en `0xC231`.

## 👥 Datos de los Personajes de Gaiden

| Personaje | ID | HP Máximo | Estado Inicial | Habilidad / Rol |
| :--- | :--- | :--- | :--- | :--- |
| **Barry Burton** | `HeroId.Barry` | 100 | Activo en Grupo | Protagonista inicial, especialista en armas pesadas. |
| **Leon S. Kennedy** | `HeroId.Leon` | 100 | Desbloqueable | Reclutado tras encontrarlo en el barco. Mayor agilidad. |
| **Lucia** | `HeroId.Lucia` | 120 | Desbloqueable | Mayor reserva de salud, crucial para la trama del virus. |

## 💻 Implementación en Unity C# (`PartyManager.cs`)

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;
using Game.Core;

namespace Game.Units {
    public enum HeroId { Barry = 0, Leon = 1, Lucia = 2 }

    [Serializable]
    public class PartyMember {
        public HeroId Id;
        public string Name;
        public int CurrentHp;
        public int MaxHp;
        public bool IsInParty;
        public bool IsPoisoned;

        public bool IsAlive => CurrentHp > 0;

        public void TakeDamage(int dmg) {
            CurrentHp = Mathf.Max(0, CurrentHp - dmg);
        }

        public void Heal(int amount) {
            CurrentHp = Mathf.Min(MaxHp, CurrentHp + amount);
        }
    }

    public class PartyManager : Singleton<PartyManager> {
        public static event Action<PartyMember> OnActiveHeroChanged;
        public static event Action<PartyMember> OnHeroDamaged;
        public static event Action<PartyMember> OnHeroHealed;

        [SerializeField] private List<PartyMember> _members = new List<PartyMember>();
        public int ActiveHeroIndex { get; private set; } = 0;

        public PartyMember ActiveHero => _members[ActiveHeroIndex];

        protected override void Awake() {
            base.Awake();
            InitializeDefaultParty();
        }

        private void InitializeDefaultParty() {
            _members.Clear();
            _members.Add(new PartyMember { Id = HeroId.Barry, Name = "Barry", CurrentHp = 100, MaxHp = 100, IsInParty = true });
            _members.Add(new PartyMember { Id = HeroId.Leon, Name = "Leon", CurrentHp = 100, MaxHp = 100, IsInParty = false });
            _members.Add(new PartyMember { Id = HeroId.Lucia, Name = "Lucia", CurrentHp = 120, MaxHp = 120, IsInParty = false });
        }

        public void RecruitMember(HeroId id) {
            var member = _members.Find(m => m.Id == id);
            if (member != null) {
                member.IsInParty = true;
                Debug.Log($"[PartyManager] {member.Name} se ha unido al grupo.");
            }
        }

        public void CycleNextHero() {
            for (int i = 1; i < _members.Count; i++) {
                int nextIndex = (ActiveHeroIndex + i) % _members.Count;
                if (_members[nextIndex].IsInParty && _members[nextIndex].IsAlive) {
                    ActiveHeroIndex = nextIndex;
                    OnActiveHeroChanged?.Invoke(ActiveHero);
                    Debug.Log($"[PartyManager] Personaje activo cambiado a: {ActiveHero.Name}");
                    return;
                }
            }
        }

        public void ApplyDamageToActiveHero(int damage) {
            ActiveHero.TakeDamage(damage);
            OnHeroDamaged?.Invoke(ActiveHero);

            // Si el héroe activo muere, buscar sustituto con vida
            if (!ActiveHero.IsAlive) {
                bool anyAlive = false;
                for (int i = 0; i < _members.Count; i++) {
                    if (_members[i].IsInParty && _members[i].IsAlive) {
                        ActiveHeroIndex = i;
                        OnActiveHeroChanged?.Invoke(ActiveHero);
                        anyAlive = true;
                        break;
                    }
                }

                // Si todos han muerto -> Game Over total
                if (!anyAlive) {
                    GameManager.Instance.ChangeState(GameState.GameOver);
                }
            }
        }

        public void CurePoison() {
            ActiveHero.IsPoisoned = false;
        }
    }
}
```
