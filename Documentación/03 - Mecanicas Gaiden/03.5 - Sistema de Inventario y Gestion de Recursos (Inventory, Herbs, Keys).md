# 03.5 - Sistema de Inventario y Gestión de Recursos (Inventory, Herbs & Keys)

Fiel a las raíces del *Survival Horror*, *Resident Evil Gaiden* impone una severa limitación de recursos:
- Un maletín con un máximo de **8 casillas para objetos** (`items[8]` en la ROM).
- Munición agrupada por tipo de arma con tope en 99 unidades.
- Sistema de hierbas curativas tradicionales (Verde, Roja, Mezclada) y Spray de Primeros Auxilios.
- Llaves maestras y tarjetas de acceso necesarias para desbloquear puertas cerradas del trasatlántico.
- Capacidad de **soltar objetos del maletín al suelo 3D** (`DropItem`) permitiendo recuperarlos más adelante.

## 📦 Recogida y Animación Sensorial (`ItemPickup.cs`)

Para dotar de retroalimentación táctil y diegética a la recolección, `ItemPickup` emplea **DOTween** tanto para la flotación idle en el mundo como para la absorción sensorial al interactuar o pasar por encima:

```csharp
using UnityEngine;
using DG.Tweening;
using Game.Interfaces;
using Game.Items;
using Game.Inventory;
using Game.Exploration;

namespace Game.Exploration {
    [RequireComponent(typeof(Collider))]
    public class ItemPickup : MonoBehaviour, IInteractable {
        [SerializeField] private ItemId _itemToGive = ItemId.GreenHerb;
        [SerializeField] private float _bobHeight = 0.25f;
        [SerializeField] private float _bobDuration = 1.2f;
        [SerializeField] private float _rotateDuration = 4.0f;

        private bool _isCollected;
        private Tween _bobTween;
        private Tween _rotateTween;

        private void Start() {
            var col = GetComponent<Collider>();
            if (col != null) col.isTrigger = true;

            // Animación idle con DOTween
            _bobTween = transform.DOMoveY(transform.position.y + _bobHeight, _bobDuration)
                .SetEase(Ease.InOutSine)
                .SetLoops(-1, LoopType.Yoyo);

            _rotateTween = transform.DORotate(new Vector3(0, 360, 0), _rotateDuration, RotateMode.FastBeyond360)
                .SetEase(Ease.Linear)
                .SetLoops(-1, LoopType.Incremental);
        }

        private void OnTriggerEnter(Collider other) {
            if (_isCollected) return;
            if (other.CompareTag("Player") || other.GetComponent<ExplorationController>() != null) {
                ExecutePickup();
            }
        }

        public void Interact(ExplorationController player) {
            if (_isCollected) return;
            ExecutePickup();
        }

        private void ExecutePickup() {
            if (InventorySystem.Instance == null) return;

            bool added = InventorySystem.Instance.AddItem(_itemToGive);
            if (!added) return;

            _isCollected = true;
            _bobTween?.Kill();
            _rotateTween?.Kill();

            // Secuencia elástica de recogida
            Sequence pickSeq = DOTween.Sequence();
            pickSeq.Append(transform.DOMoveY(transform.position.y + 0.5f, 0.25f).SetEase(Ease.OutQuad));
            pickSeq.Join(transform.DOScale(Vector3.zero, 0.25f).SetEase(Ease.InBack));
            pickSeq.OnComplete(() => Destroy(gameObject));
        }

        public string GetInteractionPrompt() => $"Recoger {_itemToGive} [E]";
    }
}
```

## 🗑️ Soltado Dinámico al Mundo (`InventorySystem.DropItem`)

Cuando el jugador descarta un objeto desde la interfaz mediante las teclas `[D]` o `[X]` (o botón Norte del gamepad), el sistema de inventario ejecuta `DropItem`:
1. Retira el `ItemId` de la lista interna `_slots`.
2. Calcula la posición en el suelo frente al jugador: `player.transform.position + player.transform.forward * 1.0f`.
3. Instancia un objeto visual con material y componente `ItemPickup` configurado con ese mismo `ItemId`.
4. El objeto aparece con animación `DOPunchScale` y entra inmediatamente en el ciclo de flotación, listo para ser re-recogido si se desea.

## 🖥️ Interfaz de Usuario y Debounce Anti-Rebote (`InventoryUI.cs`)

Para evitar bucles donde la misma pulsación abre y cierra el menú instantáneamente, `InventoryUI` implementa:
- **Cooldown de Debounce**: Ignora entradas durante los primeros `0.25s` de apertura (`Time.unscaledTime - _openedTime < 0.25f`).
- **Navegación Intuitiva**:
  - Teclas numéricas `1` a `8`: Uso directo de consumibles sobre el héroe activo.
  - Teclas `[D]` / `[X]` / `Gamepad Botón Norte`: Soltar objeto seleccionado al suelo.
  - Tecla `I` / `Tab` / `Escape` / `Gamepad Botón Este`: Cierre inmediato restaurando el estado `Exploration`.
