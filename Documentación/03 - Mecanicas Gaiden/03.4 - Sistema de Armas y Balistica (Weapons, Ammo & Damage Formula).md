# 03.4 - Sistema de Armas y Balística (Weapons, Ammo & Damage Formula)

En *Resident Evil Gaiden*, cada arma tiene una función táctica clara dentro de la barra de sincronización. Las armas se desbloquean a medida que el jugador explora el barco o supera eventos clave.

## ⚙️ Mecánica de Munición y Máscaras de Bits (Bitmasks)

En la ROM original, el desbloqueo de armas se gestionaba con una **máscara de bits de 8 bits** (`weapons_unlocked`):
- Bit 0: Cuchillo (`1 << 0` = `0x01`)
- Bit 1: Pistola (`1 << 1` = `0x02`)
- Bit 2: Escopeta (`1 << 2` = `0x04`)
- Bit 3: Lanzagranadas (`1 << 3` = `0x08`)
- Bit 4: Lanzacohetes (`1 << 4` = `0x10`)

En Unity moderno, representamos esto mediante un enumerado con el atributo `[System.Flags]`, permitiendo comprobaciones de bits directas:

```csharp
[System.Flags]
public enum UnlockedWeaponsFlags {
    None            = 0,
    Knife           = 1 << 0, // 1
    Handgun         = 1 << 1, // 2
    Shotgun         = 1 << 2, // 4
    GrenadeLauncher = 1 << 3, // 8
    RocketLauncher  = 1 << 4  // 16
}
```

## 💻 Clase de Armas en Unity (`WeaponData.cs` / `ScriptableWeapon.cs`)

```csharp
using UnityEngine;

namespace Gaiden.Weapons {
    public enum WeaponType {
        Knife = 0,
        Handgun = 1,
        Shotgun = 2,
        GrenadeLauncher = 3,
        RocketLauncher = 4
    }

    [CreateAssetMenu(fileName = "NewWeapon", menuName = "Gaiden/Combat/Weapon")]
    public class ScriptableWeapon : ScriptableObject {
        public WeaponType WeaponType;
        public string WeaponName;
        public int BaseDamage;
        public int CritMultiplier;
        public int MaxAmmo = 99;
        
        [Header("Efectos")]
        public AudioClip FireSound;
        public AudioClip EmptySound;
        public Sprite ReticleIcon;

        public int CalculateDamage(bool isCritical) {
            return isCritical ? (BaseDamage * CritMultiplier) : BaseDamage;
        }
    }
}
```

## 🎯 Estrategia Táctica de Gaiden

1. **Uso del Cuchillo**:
   - Tiene alcance reducido y poco daño, pero **nunca gasta munición**. Es vital para rematar zombies caídos o reservar balas de pistola en los primeros pisos.
2. **Impactos Críticos**:
   - Como la escopeta y el lanzagranadas infligen daño masivo con multiplicador x2, acertar en la diana crítica (`CritHalfWidth` de 2 a 4 px) es indispensable contra jefes y Tyrants.
