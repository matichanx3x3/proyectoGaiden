# 06.1 - Diagramas Mermaid de Arquitectura

Esta nota compila los diagramas visuales en **Mermaid** que describen el flujo de datos, la estructura de clases y las secuencias de interacción para el proyecto Resident Evil Gaiden en Unity.

---

## 1. Diagrama de Arquitectura de Capas

```mermaid
flowchart TD
    subgraph UI_Layer["Capa de Presentación (UI & Audio)"]
        HUD["CombatHUD / InventoryUI"]
        ReticleView["ReticleController (Canvas)"]
        Audio["AudioSystem (Música / SFX)"]
    end

    subgraph Managers_Layer["Capa de Coordinación (Managers & Eventos)"]
        GameMgr["GaidenGameManager (Singleton)"]
        CombatMgr["CombatManager (Singleton)"]
        PartyMgr["PartyManager (Singleton)"]
        UnitMgr["UnitManager (StaticInstance)"]
    end

    subgraph Domain_Layer["Capa de Dominio & Gameplay"]
        ExploCtrl["ExplorationController"]
        HeroUnit["HeroUnit (Barry, Leon, Lucia)"]
        EnemyUnit["EnemyOverworldUnit (Zombies)"]
        InvSys["InventorySystem"]
    end

    subgraph Data_Layer["Capa de Datos (Data-Driven / Scriptables)"]
        ResSys["ResourceSystem (O(1) Dictionary Cache)"]
        SO_Hero["ScriptableHero"]
        SO_Enemy["ScriptableEnemy"]
        SO_Weapon["ScriptableWeapon"]
        SO_Item["ScriptableItem"]
    end

    Managers_Layer -.->|Eventos C#| UI_Layer
    Domain_Layer -->|Solicita Estado / Triggers| Managers_Layer
    Managers_Layer -->|Spawning & Stats| Domain_Layer
    Domain_Layer -->|Consulta Datos| ResSys
    ResSys --> SO_Hero
    ResSys --> SO_Enemy
    ResSys --> SO_Weapon
    ResSys --> SO_Item
```

## 2. Diagrama de Secuencia: Transición de Exploración a Combate

```mermaid
sequenceDiagram
    autonumber
    actor Player as Jugador
    participant Explo as ExplorationController
    participant Zombie as EnemyOverworldUnit
    participant CombatMgr as CombatManager
    participant GameMgr as GaidenGameManager
    participant Audio as AudioSystem
    participant Reticle as ReticleController

    Player->>Explo: Mueve hacia adelante
    Explo->>Zombie: OnTriggerEnter2D (Contacto en pasillo)
    Zombie->>CombatMgr: StartCombat(ZombieMale, this)
    CombatMgr->>GameMgr: ChangeState(GaidenGameState.Combat)
    
    GameMgr->>GameMgr: OnBeforeStateChanged(Combat)
    GameMgr->>Audio: PlayMusic(CombatTheme)
    GameMgr->>Explo: Deshabilita movimiento
    
    CombatMgr->>Reticle: Inicializa Aguja (pos = 0, dir = +1)
    CombatMgr->>Reticle: Configura HitZone (18px) y CritZone (4px)
    
    Note over CombatMgr,Reticle: Bucle de Combate por Sincronización Activo
```

## 3. Diagrama de Secuencia: Disparo y Cálculo de Daño

```mermaid
sequenceDiagram
    autonumber
    actor Player as Jugador
    participant CombatMgr as CombatManager
    participant Inv as InventorySystem
    participant Audio as AudioSystem
    participant Enemy as ScriptableEnemy / HP
    participant Party as PartyManager

    Player->>CombatMgr: Presiona Botón A (Espacio / Trigger)
    CombatMgr->>Inv: Comprueba munición de arma equipada
    
    alt Sin munición y no es Cuchillo
        Inv-->>CombatMgr: Balas = 0
        CombatMgr->>Audio: PlaySound(EmptyClick)
    else Munición disponible
        Inv->>Inv: ConsumeAmmo(Handgun, 1)
        CombatMgr->>Audio: PlaySound(HandgunShot)
        CombatMgr->>CombatMgr: dist = abs(Needle - TargetCenter)
        
        alt dist <= CritWidth (Crítico)
            CombatMgr->>Enemy: Aplica DañoBase * 2
            CombatMgr->>Audio: PlaySound(CritSfx)
        else dist <= HitWidth (Normal)
            CombatMgr->>Enemy: Aplica DañoBase
        else dist > HitWidth (Fallo)
            Note over CombatMgr: Disparo Fallido (0 daño)
        end
        
        opt Si Zombie HP <= 0
            CombatMgr->>CombatMgr: EndCombat(victory: true)
            CombatMgr->>Party: Continúa exploración
        end
    end
```

## 4. Diagrama de Clases: Jerarquía de Unidades e Interfaces

```mermaid
classDiagram
    class IDamageable {
        <<interface>>
        +int CurrentHp
        +bool IsDead
        +void TakeDamage(int amount)
        +void Heal(int amount)
    }

    class IInteractable {
        <<interface>>
        +void Interact(ExplorationController player)
    }

    class UnitBase {
        <<abstract>>
        #UnitStats _stats
        +int CurrentHp
        +int MaxHp
        +bool IsDead
        +virtual void TakeDamage(int amount)
        +virtual void Heal(int amount)
        #virtual void Die()
    }

    class HeroUnit {
        +HeroId HeroId
        +void Initialize(ScriptableHero data)
    }

    class EnemyOverworldUnit {
        -EnemyType _enemyType
        +void Initialize(ScriptableEnemy data)
    }

    IDamageable <|.. UnitBase
    UnitBase <|-- HeroUnit
    UnitBase <|-- EnemyOverworldUnit
    IInteractable <|.. EnemyOverworldUnit
```
