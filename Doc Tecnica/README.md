## 🏛️ Estructura de la Documentación Técnica

- **`00 - Indice/`**: MOC de ingeniería, roadmap de desarrollo y estado técnico de tareas.
- **`01 - Arquitectura General/`**: Filosofía de arquitectura de software, jerarquía de GameObjects y máquina de estados global.
- **`02 - Core Systems/`**: Patrón Singleton (`StaticInstance`), `GameManager`, sistemas persistentes, `AudioSystem`, `ResourceSystem` y extensiones de código.
- **`03 - Mecanicas Gaiden/`**: Especificación de ingeniería y scripts de mecánicas (`ExplorationController`, `CombatManager`, `PartyManager`, `PushableBox`, `DoorInteractable`, `LadderZone`).
- **`04 - Fundamentos Teoricos y Diseno/`**: POO en C#, herencia vs composición, interfaces (`IInteractable`), colecciones genéricas y eventos desacoplados.
- **`05 - Scripts C# (Arquitectura Unity)/`**: Catálogo e implementación directa de los scripts C# del motor.
- **`06 - Diagramas y Canvas/`**: Diagramas Mermaid de clases, secuencias y lienzo de arquitectura técnica (`Gaiden_Architecture.canvas`).
