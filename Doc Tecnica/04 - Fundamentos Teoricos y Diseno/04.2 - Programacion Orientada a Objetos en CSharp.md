# 04.2 - Programación Orientada a Objetos en C#

La base arquitectónica de este proyecto en Unity se apoya en los principios fundamentales de la **Programación Orientada a Objetos (POO)** en C# para garantizar tipado estricto, encapsulamiento y modularidad.

---

## 🧱 Pilares de POO Aplicados a Gaiden

C# se ejecuta en el entorno controlado del CLR (*Common Language Runtime*). En nuestro proyecto de Unity, aprovechamos cada elemento del lenguaje para estructurar el dominio del juego:

### 1. Clases vs Estructuras (`class` vs `struct`)
- **`class` (Semántica de Referencia)**:
  - Se asignan en el *Heap*. Dos variables pueden referenciar la misma instancia compartida.
  - Se utiliza para entidades con identidad propia, estado mutable continuo y ciclo de vida en Unity: `UnitBase`, `CombatManager`, `ExplorationController`.
- **`struct` (Semántica de Valor)**:
  - Se asignan en el *Stack* (o embebidas dentro de su contenedor). Al asignarse o pasarse como argumento, **se copia su contenido completo**.
  - Se utiliza para paquetes de datos inmutables o livianos:
    ```csharp
    [System.Serializable]
    public struct UnitStats {
        public int Health;
        public int MaxHealth;
        public int AttackPower;
    }
    ```

---

### 2. Enumerados (`enum`)
Evitan el uso de literales o enteros arbitrarios, garantizando comprobaciones seguras durante la compilación:
```csharp
public enum WeaponType {
    Knife           = 0,
    Handgun         = 1,
    Shotgun         = 2,
    GrenadeLauncher = 3,
    RocketLauncher  = 4
}
```

---

### 3. Propiedades y Encapsulamiento
El principio de ocultación de información restringe el acceso directo a los campos internos, protegiendo las invariantes del modelo:
```csharp
public class Character {
    private int _hp;

    // Acceso público de lectura, mutación interna protegida
    public int CurrentHp {
        get => _hp;
        private set {
            _hp = Mathf.Clamp(value, 0, MaxHp);
            if (_hp == 0) OnCharacterDied();
        }
    }

    public int MaxHp { get; private set; }
}
```

---

### 4. Objetos Scriptables (`ScriptableObject`)
Los ScriptableObjects representan datos independientes de la jerarquía de escenas de Unity:
- Permiten serializar configuraciones de armas, enemigos e ítems como archivos `.asset` en el disco.
- Implementan de manera natural el patrón **Flyweight**: múltiples instancias de un zombie en el mapa comparten una única copia en memoria de sus estadísticas base (`ScriptableEnemy`).
