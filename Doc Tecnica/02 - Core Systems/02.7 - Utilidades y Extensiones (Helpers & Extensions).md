# 02.7 - Utilidades y Extensiones (Helpers & Extensions)

El archivo `Assets/_Scripts/Utilities/Helpers.cs` almacena métodos estáticos y métodos de extensión (`this`) que simplifican tareas repetitivas en Unity y proporcionan cálculos matemáticos específicos para las mecánicas de *Resident Evil Gaiden*.

---

## 💻 Implementación de `Helpers.cs`

```csharp
using UnityEngine;

namespace Game.Utilities {
    public static class Helpers {
        /// <summary>
        /// Destruye todos los hijos de un Transform de forma limpia.
        /// Uso: transform.DestroyChildren();
        /// </summary>
        public static void DestroyChildren(this Transform t) {
            foreach (Transform child in t) {
                Object.Destroy(child.gameObject);
            }
        }

        /// <summary>
        /// Ajusta una posición en el mundo 2D al centro de la cuadrícula (Grid Snapping)
        /// Útil para la navegación estilo Game Boy (tiles de 1x1 o 0.5x0.5).
        /// </summary>
        public static Vector3 SnapToGrid(this Vector3 position, float gridSize = 1f) {
            return new Vector3(
                Mathf.Round(position.x / gridSize) * gridSize,
                Mathf.Round(position.y / gridSize) * gridSize,
                position.z
            );
        }

        /// <summary>
        /// Calcula la oscilación de la aguja de combate (0 a gaugeMax).
        /// Emula la oscilación triangular del código C de la Game Boy:
        /// 49C2 reticle oscillation con rebote en los límites.
        /// </summary>
        public static float CalculateReticlePosition(float time, float speed, float gaugeMax = 120f) {
            return Mathf.PingPong(time * speed, gaugeMax);
        }

        /// <summary>
        /// Determina la dirección cardinal más cercana a partir de un vector de movimiento
        /// </summary>
        public static Vector2 ToCardinalDirection(this Vector2 dir) {
            if (Mathf.Abs(dir.x) > Mathf.Abs(dir.y)) {
                return new Vector2(Mathf.Sign(dir.x), 0);
            } else if (Mathf.Abs(dir.y) > 0) {
                return new Vector2(0, Mathf.Sign(dir.y));
            }
            return Vector2.zero;
        }

        /// <summary>
        /// Convierte un valor porcentual (0..1) al valor entero de píxeles de la Game Boy (0..120)
        /// </summary>
        public static int ToGbcGaugePixels(float normalizedValue, int maxPixels = 120) {
            return Mathf.Clamp(Mathf.RoundToInt(normalizedValue * maxPixels), 0, maxPixels);
        }
    }
}
```

---

## 💡 Ventajas de los Métodos de Extensión

1. **Legibilidad del Código**:
   - Escribir `containerTransform.DestroyChildren();` resulta mucho más limpio y expresivo que crear bucles `foreach` repetidos en múltiples scripts.
2. **Centralización Matemática**:
   - Evita duplicar fórmulas de rebote triangular o conversiones de cuadrícula a lo largo de los controladores de combate y exploración.
