# 01.3 - Ciclo de Vida y Máquina de Estados Global (Game Loop)

## 🕹️ Del Ciclo SM83 de Game Boy a Unity

En el código original desensamblado de Game Boy Color (`decompgaiden/src/state_machine.c` y `re_gaiden.h`):
- El bucle principal se ejecuta sincrónicamente sincronizado a 60 FPS con el pulso **VBlank** del procesador SM83 (Banco `00`: `0x2AE9`).
- Una variable global de estado (`game->state`, mapeada a la RAM en `0xC192..0xC194` y `0xC2E1`) bifurcaba el ciclo en cada fotograma mediante un `switch-case`.

En **Unity**, trasladamos esta máquina de estados a un gestor de alto nivel ([[02.2 - Game Manager y Arquitectura de Estados (GameManager)|GameManager]]) acoplado al bucle de eventos (`Update()`, `FixedUpdate()`) y orquestado mediante **Delegados y Eventos** (`Action<GameState>`), aplicando los fundamentos de [[04.5 - Arquitectura Basada en Eventos y Delegados]].

## 🔄 Diagrama de Transición de Estados

```mermaid
stateDiagram-v2
    [*] --> Starting: Bootstrap Awake
    Starting --> TitleScreen: Logos & Idioma listos
    TitleScreen --> Exploration: "Press Start" / Nueva Partida
    
    state Exploration {
        [*] --> FreeRoam
        FreeRoam --> CheckDoor: Colisión Puerta / Interacción
        FreeRoam --> PickItem: Colisión Item
        FreeRoam --> EncounterZombie: Colisión Zombie
    }
    
    Exploration --> Inventory: Presionar Botón I / Select
    Inventory --> Exploration: Salir del Menú
    
    Exploration --> Combat: EncounterZombie disparado
    
    state Combat {
        [*] --> ReticleOscillating
        ReticleOscillating --> PlayerShot: Disparo presionado
        PlayerShot --> DamageCalc: Hit / Miss / Crit
        DamageCalc --> EnemyTurnTimer: Si Zombie sigue vivo
        EnemyTurnTimer --> EnemyAttack: Temporizador agotado
        EnemyAttack --> ReticleOscillating: Player sigue vivo
    }
    
    Combat --> Exploration: Zombie Derrotado (Victoria)
    Combat --> GameOver: Todos los personajes de la Party con HP = 0
    
    GameOver --> TitleScreen: Reiniciar
    Exploration --> Victory: Jefe Final Derrotado
    Victory --> TitleScreen
```

## 📊 Enumeración de Estados (`GameState`)

En C# definimos los estados del juego bajo el namespace `Game.Core`:

```csharp
namespace Game.Core {
    public enum GameState {
        Starting        = 0, // Carga de sistemas y assets iniciales
        IntroLogos      = 1, // Pantallas iniciales
        TitleScreen     = 2, // Menú principal y selección de partida
        Exploration     = 3, // Exploración 3D cenital en las cubiertas y zonas de prueba
        Combat          = 4, // Modo combate 3D con retículo oscilante
        Inventory       = 5, // Pantalla de objetos, curación y equipo de armas
        GameOver        = 6, // Derrota total del grupo
        Victory         = 7  // Secuencia de escape y créditos
    }
}
```

## ⚡ Patrón de Notificación: Before y After State Changed

Para permitir que los subsistemas preparen o limpien sus recursos de forma desacoplada antes y después de cada cambio de estado, el gestor expone dos eventos estáticos:

```csharp
public static event Action<GameState> OnBeforeStateChanged;
public static event Action<GameState> OnAfterStateChanged;
```

### Tabla de Responsabilidades por Estado:

| Estado | Acciones en `OnBeforeStateChanged` | Acciones en `OnAfterStateChanged` |
| :--- | :--- | :--- |
| **`Exploration`** | Preparar retorno al pasillo. Si venía de combate, descargar `03_CombatArena` asíncronamente y destruir al enemigo del overworld. | Encender `Main Camera` en perspectiva y `AudioListener`. Reactivar movimiento del `CharacterController`. Reanudar música ambiental. |
| **`Combat`** | Apagar cámara y listener de exploración. Obtener referencia del `EnemyOverworldUnit`. | Cargar aditivamente `03_CombatArena`. `CombatArenaDirector` proyecta el enemigo 3D. Activar aguja oscilante y música de tensión. |
| **`Inventory`** | Suspender entrada de movimiento de exploración. Registrar timestamp de apertura para debounce. | Mostrar UI del maletín de 8 casillas (`InventoryUI`). Refrescar slots, munición y estado de salud/veneno del grupo. |
| **`GameOver`** | Detener oscilador del combate y silenciar música de tensión. | Disparar sonido de muerte clásico de Resident Evil. Mostrar pantalla de "You are dead" con opción de reintentar. |
