# 03.2 - Sistema de Combate, Armas & Habilidades

> [!NOTE] La Mecánica Insignia de Gaiden
> Especificación a fondo del combate en primera persona con retículo oscilante: psicología de la tensión, reglas de sincronización, arsenal de armas y fórmulas de daño.

---

## 1. Anatomía y Filosofía de la Barra de Sincronización

El combate abandona el azar tradicional de los RPGs e impone una **prueba de habilidad y reflejos bajo presión**:
- Al entrar en combate, la pantalla enfoca en primera persona al enemigo frontal.
- En la base de la pantalla oscila una **aguja blanca** sobre un medidor de `0 a 120 píxeles` a una velocidad de `3 px por frame` (60 FPS = ciclo completo en ~1.3 segundos).

```
[======================== GAUGE: 0 .. 120 px ========================]
0                                60                                120
|---------------------[   (  |  )   ]--------------------------------|
                      |   |  |  |   |
                      |   |  |  |   +-- Fin Zona de Impacto Normal (Hit Width)
                      |   |  |  +------ Fin Diana Crítica (Crit Width)
                      |   |  +--------- Centro del Objetivo (Target Center = 60)
                      |   +------------ Inicio Diana Crítica
                      +---------------- Inicio Zona Normal
                             ^
                           Aguja oscilante (3 px/frame)
```

## 2. Reglas del Disparo & Fórmulas Matemáticas de Daño

Al presionar el gatillo (Botón Sur / Espacio):
$$	ext{Distancia} = |	ext{PosiciónAguja} - 	ext{CentroObjetivo}|$$

1. **Impacto Crítico:** Si $	ext{Distancia} \le 	ext{CritHalfWidth}$
   - Daño: $	ext{DañoBase} 	imes 	ext{MultiplicadorCrítico}$.
   - Feedback: Destello blanco intenso en pantalla, sonido contundente de desmembramiento/headshot y aturdimiento del enemigo.
2. **Impacto Normal:** Si $	ext{CritHalfWidth} < 	ext{Distancia} \le 	ext{HitHalfWidth}$
   - Daño: $	ext{DañoBase} 	imes 1.0$.
   - Feedback: Salpicadura de sangre estándar y quejido del monstruo.
3. **Fallo (Miss):** Si $	ext{Distancia} > 	ext{HitHalfWidth}$
   - Daño: `0 HP`.
   - Penalización: El disparo consume munición, la aguja no se detiene y el enemigo aprovecha el tiempo de recuperación para cerrar su temporizador de ataque.

## 4. Tensión y Ataques de los Enemigos (Turn Timers)
- Cada enemigo posee un contador regresivo (`turn_timer`) en frames.
- Si el jugador duda o falla repetidamente sus disparos, el contador llega a cero y el monstruo golpea irremediablemente al personaje activo.
- Los perros (*Cerberus*) atacan cada 2.0 segundos, forzando disparos rápidos incluso sin apuntar al crítico perfecto.
