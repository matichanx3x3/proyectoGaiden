# 08.1 - Stack Técnico & Arquitectura del Motor (Unity)

> [!NOTE] Propósito de la Sección
> Documentar el motor de juego, la configuración de pipelines gráficos, los packages oficiales utilizados y la vinculación con la arquitectura C# del proyecto.

---

## 1. Entorno de Desarrollo & Motor

- **Motor de Juego:** Unity 6 (6000.x LTS)
- **Pipeline de Render:** Universal Render Pipeline (URP) optimizado para plataformas cruzadas.
- **Control de Versiones:** Git con Git LFS para texturas, modelos 3D y audio.

---

## 2. Packages & Middleware de Unity
- `com.unity.inputsystem`: Input System moderno para soporte multiplataforma unificado.
- `com.unity.cinemachine`: Gestión dinámica de cámaras de juego y cinemáticas.
- `com.unity.ai.navigation`: NavMesh para IA de enemigos e inteligencia sensorial.
- `com.unity.probuilder`: Greyboxing y prototipado rápido de layouts de niveles en el editor.

---

## 3. Arquitectura de Scripts C# del Proyecto
- **Exploración & Locomoción:** `ExplorationController.cs`, `LadderZone.cs`
- **Interactuables & Puzles:** `PushableBox.cs`, `BoxDestinationPoint.cs`, `DoorInteractable.cs`
- **Gestores (Managers):** `CombatManager.cs`, `PartyManager.cs`, `UnitManager.cs`
- **Interfaces de Usuario (UI):** `CombatUI.cs`, `ExplorationHUD.cs`, `GameOverUI.cs`, `ScreenFader.cs`
- **Datos (ScriptableObjects):** `ScriptableHero.cs`, `ScriptableEnemy.cs`, `ScriptableItem.cs`, `ScriptableWeapon.cs`
