# 02.4 - Mapeo de Controles & Esquema de Entrada

> [!NOTE] Propósito de la Sección
> Especificar el esquema de botones en mandos estándar (DualShock/DualSense de PlayStation y Mando de Xbox) y Teclado + Ratón en PC, asegurando ergonomía y accesibilidad.

---

## 1. Esquema Gráfico del Controlador (Gamepad)

```
                       [L1 / LB]                          [R1 / RB]
                 (Agacharse / Sigilo)               (Correr / Sprint)
                       [L2 / LT]                          [R2 / RT]
                 (Apuntar / Bloqueo)                 (Interacción / Cajas)
                     ┌───────────┐                      ┌───────────┐
                     │           └──────────────────────┘           │
                 ┌───┴───┐                                      ┌───┴───┐
                 │  ▲    │             SHARE    OPTIONS         │  (△)  │ Puñetazo Alto (Y)
       D-PAD ◄───┤◄   ►  │               [■]     [≡]            │(□) (○)│ Patada (X) / Puñetazo Bajo (B)
                 │  ▼    │                                      │  (⨉)  │ Salto (A)
                 └───┬───┘      (L-STICK)        (R-STICK)      └───┬───┘
                     │         [Movimiento]     [Cámara Orb.]       │
                     │          (Pulsar: L3)     (Pulsar: R3)       │
                     └──────────────────────────────────────────────┘
```

---

## 2. Tabla Maestra de Asignación de Controles

| Acción del Jugador | PlayStation (PS4/PS5) | Xbox (One/Series) | PC (Teclado + Ratón) | Comportamiento & Reglas |
| :--- | :--- | :--- | :--- | :--- |
| **Mover Personaje** | Stick Izquierdo (L-Stick) | Stick Izquierdo (L-Stick) | `W, A, S, D` | Desplazamiento en 8 direcciones o analógico 360°. |
| **Controlar Cámara** | Stick Derecho (R-Stick) | Stick Derecho (R-Stick) | Movimiento del Ratón | Órbita alrededor del personaje en vista 2.5D/3D. |
| **Puñetazo Alto (Rápido)** | Triángulo (`△`) | Botón `Y` | `Clic Izquierdo` / `Ctrl` | Golpe ágil. Enlace de inicio para combos. |
| **Puñetazo Bajo / Rompeguardias** | Círculo (`○`) | Botón `B` | `Alt` / Tecla `E` | Ataque pesado bajo. Rompe bloqueos ligeros. |
| **Patada / Golpe Medio** | Cuadrado (`□`) | Botón `X` | `Shift` / Tecla `Q` | Golpe de impacto con retroceso sobre el rival. |
| **Salto** | Equis (`⨉`) | Botón `A` | Barra Espaciadora (`Space`)| Salto vertical; permite rebotar en paredes. |
| **Patada Voladora** | `⨉` + `□` | `A` + `X` | `Espacio` + `Shift` | Salto y patada descendente en diagonal. |
| **Patada Deslizante (Slide)**| `⨉` + `△` | `A` + `Y` | `Alt` + `Ctrl` | Deslizamiento a ras de suelo; sortea trampas bajas. |
| **Agacharse / Modo Sigilo** | `L1` (o pulsar `L3`) | `LB` (o pulsar `LS`) | Tecla `C` | Reduce el ruido de pasos a cero y baja la silueta. |
| **Correr / Sprint** | `R1` | `RB` | `Shift` (Sostenido) | Incrementa la velocidad a costa de estamina. |
| **Interacción con Entorno** | `R2` | `RT` | Tecla `F` | Empujar cajas, accionar palancas, subir escaleras. |
| **Bloqueo / Parry** | `L2` | `LT` | `Clic Derecho` | Bloquea daño; en el frame justo ejecuta parry y stagger. |
| **Pausa / Menú In-Game** | Botón Options (`≡`) | Botón Menú (`≡`) | Tecla `Escape` (`Esc`) | Pausa la acción y despliega el menú de opciones. |

---

## 3. Filosofía de Entrada & Accesibilidad
- [x] **Sensibilidad de Sticks Ajustable:** Deslizadores para ejes X e Y por separado.
- [x] **Remapeo Completo:** El usuario puede reasignar libremente cada botón desde la pantalla de opciones.
- [x] **Modo Asistencia:** Opciones para cambiar acciones sostenidas (Hold) por alternadas (Toggle) para correr o agacharse.
